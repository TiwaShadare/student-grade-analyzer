# Student Grade Analyzer

## Overview

The Student Grade Analyzer is a simple Python application that reads student grade data from a CSV file, calculates individual averages, assigns letter grades, and generates class-level statistics.

This project demonstrates foundational programming and data processing concepts.

## Technologies

- CSV

- Input, processing, and output
- Variables
- Functions
- Conditional statements
- Loops and iteration
- Lists
- Dictionaries
- File handling
- Data processing
- Basic statistical calculations

## Features

The program:

- Reads student grades from a CSV file
- Calculates each student's average
- Assigns a letter grade
- Displays individual student results
- Calculates the overall class average
- Identifies the highest-performing student
- Identifies the lowest-performing student

## Project Files

### grade_analyzer.py

## How to Run

1. Download or clone the repository.
2. Make sure Python is installed.
3. Open a terminal in the project directory.
4. Run:

    python grade_analyzer.py

## Example Output

The program produces a student grade report showing each student's numerical average and letter grade. It also calculates the overall class average and identifies the highest and lowest averages.
